In legacy operating systems, observability and debugging are fundamentally broken by **probe effects, cache pollution, and intrusive execution halts**:
1. **The Heisenbug Dilemma (`ptrace`, eBPF, `gdb`, `perf`):** Inserting dynamic breakpoints or software probes overwrites machine instructions, flushes CPU pipeline stages, invalidates instruction caches, and introduces microsecond-scale execution delays. In high-frequency trading or hard real-time systems, the simple act of observing a bug alters micro-architectural timing so drastically that the bug vanishes.
2. **The Archaic JTAG Bottleneck:** Low-level silicon debugging still relies on 1980s-era JTAG/SWD physical headers and external In-Circuit Emulators (ICE). Connecting an external probe requires physical board access, freezes clock domains across the entire chip, disrupts PCIe link training, and drops network link states.
3. **Core-Dump Inefficiency:** System panics flush unformatted multi-gigabyte memory dumps to slow disk drives, taking seconds or minutes of catastrophic downtime while providing only a dead, static snapshot stripped of the temporal execution trajectory that led to the fault.
